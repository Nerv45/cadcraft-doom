# CADCraft DOOM changed files

The source changes add an optional, in-process Windows DoomGeneric backend,
viewport mode, UI commands/input, IWAD validation, tests, build metadata and docs.
The standalone source crate is registered with the repository layering checker.

The sibling outputs directory additionally contains the ready Windows executable,
BAT/PowerShell launchers, user-supplied DOOM1.WAD, Russian launch instructions,
hashes and verification evidence. These runtime deliverables are outside this
source Git checkout. No WAD is added to the source repository.
