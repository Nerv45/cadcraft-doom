# Лицензионное решение для CADCraft DOOM — 26 октября 2026

## Решение

Целевая лицензия программной части и объединённого приложения: **GNU GPL
version 3 or any later version (`GPL-3.0-or-later`)**. Это обоснованный выбор
для состава программы, а не уже установленное разрешение на весь vendored код.
Публикация текущего объединённого EXE пока не одобрена: для четырёх участвующих
в сборке файлов DoomGeneric не удалось однозначно подтвердить версию GPL.

MIT/Apache/MPL и лицензии шрифтов сохраняются для соответствующих компонентов.
Нельзя объявлять всё содержимое репозитория/архива исключительно GPLv3+, удалять
исходные notices или выдавать намерение автора форка за разрешение чужих авторов.
Тексты третьих лиц и их исходные заголовки не перелицензированы.

## Что проверено и чем уточнён предыдущий отчёт

Проверены закреплённая ревизия DoomGeneric
`e257a09527062bfb986b6e5e0780839b6cbd5b71`, её доступная Git-история,
список компилируемых C-файлов, локальные include, Cargo.lock, сохранённый граф
Windows metadata, лицензии критичных пакетов, bundled fonts и брендовые условия.
Никаких обращений к авторам, публикаций, push или переписывания истории не было.

Отсутствие заголовка **не означает** GPL-2.0-only и не доказывает отсутствие
любого разрешения. Однако общая применимость лицензии и право выбрать GPLv3+
должны быть установлены. FSF отдельно поясняет неоднозначность одного текста
GPL в корне без заявления о том, к каким файлам он применяется:
https://www.gnu.org/licenses/gpl-faq.en.html#LicenseCopyOnly .
GPLv2 §9 допускает выбор версии при отсутствии указанной версии для Program,
но сначала нужно установить применимое разрешение; этот пункт не создаёт
произвольное новое разрешение для вкладов третьих лиц.

В DoomGeneric root LICENSE добавлен коммитом
`0b085de3725d60d24ed4dac4dfed68a3aca86140` (2019-08-18), это текст GPLv2.
README сохраняет историческое описание 1997 года; явного общего or-later grant
для всех новых вкладов я не нашёл. Старое non-profit описание не используется
как ограничение явно GPL-лицензированных файлов. GitHub badge и практика чужих
форков не являются достаточным основанием для изменения версии лицензии.

## Файлы DoomGeneric, для которых требуется уточнение

Из 203 файлов 176 имеют явный GPL-2.0-or-later notice, sha1.c — GPL-3.0-or-later,
26 не имеют явного per-file grant. Консервативный граф сборки/include выделяет:

Это консервативный лексический include-граф, а не трассировка препроцессора:
ветви #if не исключались. Поэтому он может включать неактивные include, но не
используется для необоснованного исключения этих файлов из проверки.
Оставшиеся 22 файла находятся вне этого графа, но остаются в vendored source
архиве; их лицензии также надо сохранить/прояснить при его распространении.
Подробная история всех 26 файлов: unheaded-file-history.json. Автор коммита не
автоматически доказанный единственный правообладатель. На малый размер некоторых
файлов и возможную неохраноспособность я не опираюсь для снятия блокировки.

Предмет необходимого разъяснения upstream: какие версии GPL разрешены для
четырёх перечисленных файлов и всех затронутых вкладов, а также для оставшихся
распространяемых файлов без notices. Подтверждение может быть явным upstream
лицензионным заявлением с обоснованными полномочиями авторов; просто заменить
LICENSE в нашем форке недостаточно. Черновик обращения подготовлен ранее и не
отправлялся. Найден уже существующий независимый upstream PR #41
(https://github.com/ozkl/doomgeneric/pull/41), создан 2026-10-18 автором RBraga01.
Он запрашивает разрешения для тех же config.h/doomgeneric.c/doomgeneric.h/dummy.c
и icon.c. На 2026-10-26 PR открыт, не merged, comments/reviews пусты. Это
подтверждает наличие публичного вопроса, но не даёт лицензии. См.
upstream-clarification-status.json; никакой запрос нами не публиковался. Если разрешение только GPLv2-only, эта комбинация потребует
отдельного технического решения и повторной проверки, а не смены надписи LICENSE.

### MPL-2.0 acadrust

В исходниках acadrust не найдено отдельного прикреплённого Exhibit B notice.
Стандартный текст Exhibit B внутри полного LICENSE не превращает пакет в
Incompatible With Secondary Licenses. При объединении с GPL-кодом применим
MPL §3.3: дополнительно предоставлять Covered Software по GPL Secondary License,
сохраняя возможность использовать его по MPL и сохраняя notices. Явно указать
путь к точным исходникам acadrust; не удалять MPL-заголовки и не объявлять
исходную библиотеку безусловно GPL-only. Изменения в библиотеку не вносились.
MPL §3.2–3.4: https://www.mozilla.org/en-US/MPL/2.0/ .
Разъяснения Q14/Q25: https://www.mozilla.org/en-US/MPL/2.0/FAQ/ .
MIT-notices отдельных тестовых DWG fixtures внутри acadrust также сохранены.

## Шрифты: обнаруженный и исправленный пробел

epaint_default_fonts 0.36.2 включает отдельные ресурсы с собственными лицензиями:
Ubuntu-Light (Ubuntu Font Licence 1.0), NotoEmoji (OFL 1.1), Hack
(MIT + унаследованная Bitstream Vera license/public-domain DejaVu) и emoji-icon-font
(MIT, John Slegers). Одной строки Cargo license недостаточно для всех notices.

В прежний отдельный набор licenses не попали Hack-Regular.txt и
emoji-icon-font-mit-license.txt. Оба скопированы из точного пакета без изменений;
добавлены исходные copyright/license строки из name tables четырёх TTF.
Шрифтовые бинарники не менялись. UFL/OFL допускают bundling/embedding при
сохранении своих условий; шрифты не перелицензируются в GPL.
Источники: https://ubuntu.com/legal/font-licence и
https://openfontlicense.org/how-to-use-the-ofl/ .

Полный source ZIP уже содержал исходные font notices внутри vendor-deps;
старый binary ZIP не содержит двух этих standalone notices. Старые архивы и
их SHA256SUMS не изменены. Перед публичным выпуском требуется новая упаковка
обоих артефактов из согласованного состояния исходников/документов. Это не
требует изменений игрового кода, но не позволяет называть старый ZIP готовым
публичным релизом. См. font-notice-correction.json и font-copyright-metadata.json.

## ArtCraft и история Git

Проверка истории через GitHub commit API: восемь artwork-файлов и
LICENSE-brand.txt добавлены вместе в
`d9ab00c53c1250bb2e681bf7b26044c78888af3b` (2026-10-06). Изменений этих
условий по указанному пути до закреплённого base commit не найдено; нормализованный
текст исходного файла совпадает с текущим (CRLF/LF отличается только технически).
В проверенной истории CADCraft не найдено более раннего MIT/Apache grant на
эти artwork-файлы. Это не утверждение о любом возможном разрешении вне этого
репозитория. Источник: cadcraft-brand-history.json и
https://github.com/storytold/cadcraft/commit/d9ab00c53c1250bb2e681bf7b26044c78888af3b .

LICENSE-brand.txt различает разрешённые копии репозитория/официальный CADCraft
и модификации: у последних убрать ArtCraft marks, не называть продукт ArtCraft
и не создавать впечатление одобрения. Простое текстовое указание происхождения
прямо разрешено. В текущем дереве восемь PNG/SVG удалены, Terms и copyright
сохранены. Отдельная CADCraft drafting icon атрибутирована MIT OR Apache-2.0,
это не удалённый ArtCraft mark. Уведомления об авторах удалять нельзя.

Уточнение прежнего блокера: **наличие исторических логотипов само по себе не
доказывает запрет обычного GitHub-форка**. GitHub Terms D.5 явно предоставляет
пользователям право делать копии публичного репозитория через fork внутри
сервиса: https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#d-user-generated-content .
Это дополнительное платформенное разрешение. Оно не превращает marks в GPL,
не разрешает рекламировать нашу модификацию логотипом ArtCraft и не является
общим разрешением на любое распространение этих файлов вне сервиса.
Terms D.6 (inbound=outbound) также не доказывает сам по себе GPLv3 grant для
всех исторических DoomGeneric-вкладов; применимые исходные условия надо знать.

Поэтому прежняя рекомендация обязательно получить разрешение только из-за
самого существования Git-истории была слишком категоричной. Для обычного форка
с сохранённой исходной историей и удалёнными marks в текущей версии есть
прямое основание в GitHub Terms; это не blanket trademark licence. Граница
между платформенным копированием, историческим отображением и использованием
знака как бренда важна; утверждение о всеобщем запрете/всеобщем разрешении
исторических файлов было бы необоснованным.

Практический вариант выпуска: GitHub fork с честной историей, debranded текущим
деревом, текстовой атрибуцией и release/source ZIP без .git и без ArtCraft marks
(как уже подготовлено). Не помещать исторические marks в release/маркетинг и не
добавлять старые ссылки/баннеры официального ArtCraft в README модификации.
Для распространения отдельного bundle Git-истории вне GitHub, повторного
использования логотипов или иных выходящих за разрешение действий — получить
письменное разъяснение либо исключить такие файлы. Историю сейчас не переписывал.

## Условия окончательного выпуска

1. Установить GPLv3-or-later права на спорный DoomGeneric-код; разрешение владельца
   нашего форка не заменяет разрешения исходных правообладателей.
2. Оформить лицензию программной части GPL-3.0-or-later, сохранив исходные component
   licenses и условия отдельно лицензированных ресурсов. Для MPL оформить §3.3.
3. Перепаковать notices, исходники и EXE в согласованные артефакты; приложить
   точные Corresponding Source, Cargo.lock, build scripts и новые checksums.
4. Не включать DOOM1.WAD, runtime-копии, saves, токены, логи или restricted marks.
5. Публиковать только после отдельного одобрения. Никаких GitHub изменений не было.

Таким образом, **с выбором целевой лицензии определились: GPL-3.0-or-later**.
**Разрешение опубликовать текущий продукт под ней пока не доказано** из-за
конкретно названных upstream-файлов. Зависимости Apache/MPL сами по себе не
являются причиной заменить эту лицензию или отказаться от встроенного Doom.
